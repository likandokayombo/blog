# UI Skill

Use this skill when creating or modifying visual components.

## Before Creating UI

Inspect:

- Existing components
- Existing layout components
- Existing typography
- Existing spacing patterns
- Existing responsive behavior

Reuse existing patterns whenever possible.

## Design Principles

The UI should be:

- Minimal
- Clean
- Responsive
- Accessible
- Consistent
- Content-focused

Avoid unnecessary visual complexity.

## Tailwind

Use Tailwind utilities following the project's existing conventions.

Prefer composition of utilities over large custom CSS blocks.

## Responsive Design

Design for:

- Mobile
- Tablet
- Desktop

Do not assume desktop-only layouts.

Avoid horizontal overflow.

## Components

Keep components focused.

Prefer composition over large components containing unrelated functionality.

## Accessibility

Interactive elements must:

Have meaningful accessible names.
Be keyboard accessible.
Have appropriate focus states.

Images should use appropriate alt text.

## Animations

Do not introduce animation libraries unless explicitly requested.

Prefer simple CSS transitions when animation is necessary.

## Visual Changes

When modifying existing UI:

Preserve existing visual identity.
Avoid changing unrelated components.
Check mobile layouts.
Check typography and spacing.
